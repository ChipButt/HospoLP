# Customer editor setup

Chip In Websites uses Pages CMS as the V1 editing layer. `.pages.yml` exposes only routine business content; CSS, JavaScript, theme settings, deployment and repository controls are not exposed.

## Agency setup
1. Install/connect the Pages CMS GitHub App to the customer repository.
2. Open the repository in the hosted Pages CMS app and verify every editor screen loads.
3. Invite the business owner/manager as a collaborator by email.
4. Test one change to opening hours and confirm it commits to GitHub and appears on the live site.
5. Give the customer the editor URL and their login instructions only; do not train them on GitHub.

## Customer can edit
Homepage/about wording, phone/email/social link, announcement banner, opening hours, drinks, food/menu prices and availability, events, facilities and gallery images.

## Customer cannot edit
Theme colours, fonts, layout, HTML, CSS, JavaScript, deployment, domain configuration, `.pages.yml`, collaborator management or repository settings.
