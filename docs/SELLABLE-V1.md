# Chip In Websites Sellable V1

## What is included
A bespoke-designed hospitality landing website using the Chip In Websites capability package, GitHub-managed deployment, responsive/mobile treatment, contact/location actions, opening hours, announcement, food/drinks, events, facilities, gallery and a restricted basic content editor.

## Optional integrations
External table-booking link, WhatsApp, Instagram, manually curated reviews and specials. These are integrations/fields, not promises that Chip In Websites itself operates a reservation or review platform.

## Not included in V1
A DIY page builder, customer layout editing, automatic Google-review ingestion, custom analytics platform, customer GitHub access, or a multi-tenant SaaS dashboard.

## Sales workflow
Build initial client site -> client approves -> connect domain -> configure editor access -> launch -> 10-minute handover. Routine content is self-service. Structural/design/functionality changes are developer work.

## Definition of done
The software package is sellable when one reference client has completed an end-to-end production launch including real domain, approved media, authenticated editor access and a successful customer edit-to-live test.
