# Launch checklist

## Customer information
- [ ] Business name/address/phone/email confirmed by the customer
- [ ] Opening hours confirmed immediately before launch
- [ ] Food, drinks and event information confirmed
- [ ] Social/booking links confirmed
- [ ] All prototype imagery replaced with business-owned or approved images
- [ ] Official logo/brand assets installed where supplied

## Website
- [ ] Mobile navigation tested
- [ ] Call, email and directions buttons tested
- [ ] Opening-status display checked against today's hours
- [ ] Food/drinks/events visibility toggles tested
- [ ] Gallery opens and images have useful alt descriptions
- [ ] Homepage title and description checked
- [ ] No placeholder/example content remains visible

## Editor
- [ ] Pages CMS connected to this repository
- [ ] Customer invited as an email collaborator
- [ ] Test edit saved from customer/editor account
- [ ] Test change visible on public site
- [ ] Customer cannot access design/deployment controls through the content editor

## Launch
- [ ] GitHub Pages enabled for this repository
- [ ] Custom domain configured
- [ ] DNS points to the deployment
- [ ] HTTPS enforced once certificate is available
- [ ] Final mobile + desktop check on the real domain
- [ ] Customer given public URL and editor access
