# Mim's Flans

Client-specific HospoLP website for Mim's Flans.

## Included
- Responsive public website
- Editable content for opening hours, menu, events, facilities and gallery
- Pages CMS configuration for customer updates
- GitHub Pages deployment workflow
- Validation workflow
- `/edit/` shortcut to the customer editor

## Client editing
Routine content is edited through Pages CMS, not through GitHub. The client does not need to edit code, CSS, deployment settings or repository files directly.

## Launch
Enable GitHub Pages with **Settings → Pages → Source: GitHub Actions**. The preview will then be available from the repository's GitHub Pages URL. A custom domain can be connected later.
