# The Bulls Head — Bidford-on-Avon

Reference client for the HospoLP hospitality website package.

## Product rule
This is a prebuilt, professionally configured website. The customer receives the live site plus a restricted content editor for routine updates. They do not receive a page builder, source-code editor, GitHub access or deployment controls.

## Client-specific freedom
The shared HospoLP package defines capabilities, not appearance. This business may have its own layout, section order, typography, colours, imagery and client-specific components.

## Customer-editable content
Opening hours, contact details, announcements, food/drink items and prices, events, facilities and gallery images.

## Developer-controlled
Layout, components, navigation architecture, styling system, integrations, deployment and editor permissions.
