# HospoLP Product Definition

HospoLP is sold as a **prebuilt hospitality website package**, not as a DIY website builder.

## What the customer receives

1. A professionally designed website, built and launched for them.
2. Their website is deployed through the developer-controlled GitHub workflow.
3. A simple backend editor for everyday content changes.

## What the customer can edit

The backend editor should expose only operational content such as:

- opening hours
- contact details
- homepage/about copy
- food and drink items
- prices
- events and notices
- gallery images
- downloadable menus / PDFs
- simple availability / featured / visible toggles

## What the customer cannot edit

Customers should not have access to:

- GitHub
- code
- CSS
- page layout
- navigation structure
- components
- deployment settings
- hosting configuration
- developer-only theme controls unless intentionally exposed

## Business model

The site is initially designed and set up by the developer for each business.

The **package and operating model stay consistent**, but the actual website may be tailored per business with different:

- layouts
- visual style
- section order
- branding
- typography
- imagery
- custom components

This is not a clone-template service. It is a repeatable website system with bespoke presentation per client.

## Customer promise

The simplest customer-facing explanation is:

> We build and launch your website for you. You then get a simple editor to update the everyday information yourself.

Anything involving redesign, new pages, layout changes, new integrations or custom functionality remains developer work.
