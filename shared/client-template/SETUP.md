# New client setup

1. Copy this client structure to `businesses/<business-slug>/`.
2. Fill business identity, contact details and domain.
3. Choose required modules.
4. Build the client-specific visual treatment: logo, type, colour, imagery, layout and section order.
5. Populate initial content.
6. Configure the restricted editor against this business only.
7. Deploy the public `site/` to the client's domain.
8. Test mobile, links, hours, menu/event toggles, editor saves and deployment.
9. Give the customer only their public URL and editor URL/login.

Do not treat this as a visual clone template. The package is reusable; the presentation is bespoke.
