# HospoLP package

Every customer receives the same service package, not the same visual template.

## Included capabilities
- Responsive prebuilt website
- Custom business branding and design pass
- Opening hours
- Contact/location information
- Announcement banner
- Food and drink content
- Events
- Facilities
- Gallery
- SEO/local-business metadata
- Restricted customer content editor
- GitHub-backed deployment managed by the developer

## Design rule
Business sites can override shared presentation freely. Shared code should be used for stable behaviours and data contracts only. Do not force a client to look like another client to preserve reuse.

## Editor rule
The editor is deliberately not a website builder. Customers edit operational content. Design, structure and deployment remain developer-managed.
